# Game images

Emoji graphics in this folder (named by Unicode code point, e.g. `1f455.svg`)
are from **Twemoji** — Copyright 2019 Twitter, Inc and other contributors;
maintained at https://github.com/jdecked/twemoji — licensed under
**CC-BY 4.0**: https://creativecommons.org/licenses/by/4.0/

The photos and illustrations named by word (e.g. `durian.jpg`, `knee.jpg`,
`kidney.png`) are from **Wikimedia Commons**. `credits.json` records, for
each one, the Commons file it came from, its author, its licence (with a
link) and the source page. They have been cropped and/or padded to a square
and resized to 320 × 320 px; each adapted picture is shared under the same
licence as its original. The same credits are shown on the Games page under
"Picture credits".
